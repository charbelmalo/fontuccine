Scope of this study

Horizontal stretching only. Vertical and dual-axis rendering are not supported. The native variable-font tier follows the font’s designed width range and uses a maximum of 1.5× in this demo; it is not the same deformation as the outline tiers. This fixture uses Roboto Flex TrueType, with its OFL licence included. WOFF2 outlines and CFF2 variation interpolation are outside the supported demo scope.

Reduced motion uses a static SVG presentation. Width is held at 1× and the width controls are disabled while this preference is active. Browser fallback and parser notes appear below.
