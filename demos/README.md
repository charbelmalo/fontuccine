# README browser capture

`demo-horizontal.png` is a direct screenshot of the built public `Fontuccine.attach()`
API in headless Chrome, using the same licensed
[Roboto Flex TTF](../playground/public/fonts/RobotoFlex-VF.ttf) for native DOM text,
CSS `scaleX(2.5)`, and the forced WebGL tier. It shows horizontal stretching only.
The font's [SIL OFL notice](../playground/public/fonts/OFL.txt) remains with the fixture.

From the repository root:

```sh
npm ci
npm --prefix playground ci
npm test
npm run typecheck
npm run harness
npm run demo:capture
```

Set `CHROME_PATH=/absolute/path/to/chrome` for both browser commands if Chrome
is not in a detected location. The capture uses ANGLE SwiftShader, a fixed 2×
DPR, 48 px / weight 700 / optical sizing auto, and no effects. A short linear
easing tween reaches exactly 2.5× before capture (a spring parks within its rest
tolerance). It always rebuilds
`dist/`; it does not use Vite source aliases.
`npm run demo:capture -- --output /path/to/directory` saves a trial capture
without replacing these files.

Before saving, the script verifies the loaded native font, resolved tier, real
width ladder and base axis location, and residual uniforms at an actual GPU
draw. A non-pausing Chrome debugger breakpoint observes the plan passed to the
renderer; a pass-through draw observer reads the real GPU uniforms. Neither
changes the renderer's calculations. The script also checks settled specimen
pixels change from 1× to 2.5×, no page overflow or console warnings/errors occur,
and the captured WebGL ink overlaps a matching SVG reference by at least 0.93
IoU. `npm run harness` separately runs the existing pixel and torn-island gates.

`demo-horizontal.capture.json` records the source revision/tree, built JavaScript
hashes, script and TTF hashes, base and width-axis instances, real GPU residual,
browser/platform/viewport, pixel results, and final PNG hash. Its source revision
identifies the checkout captured, rather than the later commit adding the image.
The screenshot is saved directly, without registration, rescaling, or retouching.

This single-font, horizontal Chrome comparison does not establish other fonts,
browsers, compression, vertical/dual-axis rendering, or quantitative diagonal
thickness claims. The other SVG/PNG illustrations are generated by
`npm run demo` from the core mathematics and are not renderer captures.
